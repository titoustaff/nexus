# nexus — site de la suite GolfNexus

Pages publiées (GitHub Pages) : `https://titoustaff.github.io/nexus/<module>/`.

Chaque module y publie son dossier avec son script `publier.sh` ; les briques communes sont dans `commun/v1/`.
